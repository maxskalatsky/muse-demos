# muse-demos

Demo outputs built with Muse (Sarah), Max Skalatsky's AI build partner.

## Demos

- **fabric-intent/** — Fabric Intent Copilot: plain-language network requests translated to
  structured intent by a fine-tuned open-weight model (Llama 3.1 8B), with policy checks,
  typed approvals, an Inference Exchange placement advisor, and a full audit trail.
  Prototype — not production.
- **hii-suite/** — HII mission-tech prototype suite: dark-vessel anomaly triage (Gathering),
  TCPED triage copilot (Synthesis), and base-year evidence dashboard (Display).
  From first sighting to final report.
